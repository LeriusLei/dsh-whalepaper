# 0.6.1：控制台与虎鲸动作修复

日期：2026-11-04。

## 控制台

旧版控件先在界面里显示新值，再向宿主异步保存；宿主回读较慢时，任何旧快照通知都会覆盖正在拖动的值。快速切换显示壁纸、时段、构图也会遇到同一问题。此前只测试了没有宿主异步往返的本地存储路径，因此未覆盖用户环境中的竞态。

现在两处面板共用带字段版本的乐观状态：操作立即显示并投影到壁纸；每次只发一个宿主请求，其间后续操作按字段合并。旧请求的回读不能覆盖新操作，恢复默认也不会抹掉其后作出的修改。表单还在加载时先保留操作，等宿主就绪后写入。

保存失败保留当前调整，显示失败提示和「重试保存」，不再把未保存的值说成已保存。原生卡片与 ≈ 面板共用状态。控件明确启用 pointer-events 和 no-drag；重复通知不再给数值相同的滑条重设 value。亮度范围在 Host schema 与两处界面统一为 60–100%。仅更改滤镜不再重新调度动画 RAF。

## 活动频率

旧版只有大虎鲸的跃出计时有限，首次至少 480 个模拟秒，之后 900–1320 个模拟秒。安静模式将模拟速度乘以 0.72，折合首次至少 11.1 分钟、后续约 20.8–30.6 分钟，且还要等位置、朝向和其他行为条件满足。两头小虎鲸从未被安排自然跃出。

旧版三头都可以游动、下潜、觅食、侧翻和出水换气。换气成功后等待 230–390 个模拟秒再申请下一次；仅部分换气产生可见喷雾。自然侧翻约 235–375 个模拟秒后再申请，并受深度、猎物和临近出水条件限制；只有约 22% 申请是完整翻滚。上述间隔都是行为申请时间，不是必定看到动作的精确时刻。

新版增加鲸群活动时钟，按壁纸可见且未暂停的观看时间计时：首次约 10 分钟，之后每 9–11 分钟申请一次明显活动，跃出、完整翻滚、出水喷雾轮换。动作仍需自然调整朝向、深度和姿态，实际画面会稍晚。三头轮流分配不同角色，每头都能做三类动作；不是三头每十分钟同时表演同一个动作。安静游动仅减慢游动模拟，不再拖慢这只活动时钟。暂停、隐藏页面时不累计观看时间。

普通巡游、觅食、深浅潜行、轻微侧翻和自然换气继续在两次明显活动之间进行。喷雾仍来自真正露出水面的呼吸孔，落水飞溅仍来自向下穿过水面的身体位置，活动调度不会瞬移虎鲸。

## 验证与更新

新增延迟宿主测试覆盖旧值回读、连续拖动、不同参数交错、显示开关、加载期间操作、失败重试、恢复默认及后续操作。真实 Edge 无头浏览器执行鼠标拖动、八个参数、刷新恢复和失败/重试。

长时间测试使用实际 world/rig 模拟而非宣传视频演示入口，检查安静模式下三头各自真正产生跃出、落水、完整翻滚和喷雾事件，并保留几何与连续运动回归。

安装 0.6.1 后按宿主提示重启/重新加载插件。既有时段、构图与滤镜不需要清空，字段和 profile 配置格式保持兼容。可从设置状态行确认保存完成。
